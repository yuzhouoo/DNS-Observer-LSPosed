# DNS Observer v0.6.0-beta2

Android 16 / ColorOS 16, KernelSU Root, LSPosed Modern API 102.

- 继续保留系统 DNS 观察、原有 IPv4 UDP/TCP 53 REDIRECT 及主/从/备 DNS、测速、历史、手动停止。
- IPv6 TPROXY 当前仍为**仅本 App UID + 2001:db8:ffff::53/128 + UDP/TCP 53** 的限时实验，不开放全机接管或开机自启。Root 代理限时 145 秒，专用防火墙规则的独立看门狗为 180 秒。
- 页面移除已验证完成的旧分阶段实验入口、无效的 IPv6 NAT 勾选项、重复测速按钮；旧底层恢复功能保留。缩短文案与长日志区域：只显示最近 6 行、完整日志可滚动查看/复制；清空日志仅删除 App 保留的文字，不删 DNS 数据库/配置、不改网络规则，运行中后续新日志仍可能到来。
- 新增 12 次并发请求试运行自检（6 UDP + 6 TCP，固定 4 线程）。仅生成一行统计而不输出每次成功的网络明细；压力测试失败不会自动修改路由，普通单次健康检查失败仍会恢复。
- 试运行结束后仍执行 `VERIFY_CLEAN`，保留应急恢复 IPv6 临时规则入口。日志截断上限 10k 字符。
- 最近 DNS 测速历史默认折叠，最多读取 12 个汇总与 18 个逐 IP 项；不删除数据库的存量历史。

## 验证范围

此 APK 的 CI 编译和模拟规则测试不能替代 OnePlus 12 实机的并发、超时/进程异常退出、恢复规则完整性验证。安装后请先停止原来的试运行，运行一次 beta2 并验证停止后 `VERIFY_CLEAN`。

历史版本的技术实现和恢复方案可通过 GitHub Commit 历史追溯。
